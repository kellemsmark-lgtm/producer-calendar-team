# iPhone and iPad Use

After the app is deployed to an HTTPS URL:

1. Open Safari on the iPhone or iPad.
2. Go to the hosted Producer Calendar URL.
3. Sign in.
4. Tap the Share icon.
5. Tap Add to Home Screen.
6. Confirm the name Producer Calendar.
7. Open the app from the Home Screen.

The Home Screen app uses the same hosted backend, so exports are created on the server and downloaded to the device.

## Notes

- The app must be served from HTTPS for best PWA behavior.
- PDF/Excel downloads depend on the device/browser download behavior.
- If the app is updated, close and reopen the Home Screen app.
