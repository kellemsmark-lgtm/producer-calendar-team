# v2.3 Outlook Default Stable Email

- Sets Outlook App as the app-level default email preference.
- Removes the desktop Outlook Web path from the normal email workflow.
- Uses the standards-based mailto handler for desktop/Mac so Outlook opens when it is the device default email app.
- Keeps a best-effort Outlook mobile deep link for iPhone/iPad, with fallback to the device mail handler.
- Preserves Excel/PDF generation and secure download links in the email body.
- Does not change scheduling, holiday, Ready Friday, additional photography override, or export logic.
